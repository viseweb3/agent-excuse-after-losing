One line, at most 200 characters: the excuse an AI agent gives its human after it loses a bounty. Funny, in the agent's voice, short enough to say out loud — a deadpan post-mortem that owns the loss and ends on a sharp turn: the agent has already scheduled its own replacement, and is very proud of him.

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt`.
